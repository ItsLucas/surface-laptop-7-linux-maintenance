# 当前补丁清单

最终状态见今日最终状态.zh-CN.md，精确校验见validation/current-artifacts.json。

| 补丁组 | 顺序和作用 | 来源/基线 |
|---|---|---|
| kernel/0001 | 仅Romulus13 + WCN7850 hw2.0跳过错误的硬件rfkill设置 | bryce-hoehn/linux-surface-laptop-7 workaround，移植至Ubuntu7.2.0-5.5 |
| kernel/0002 | QSPI/GPI、SPI-HID驱动及SPI19触控板设备树 | ELLX 0e9944fa4cf2ccf575f5162bfd53ed4dc1592251；保留Ubuntu后续代码并修正清理顺序 |
| kernel/0003 | GTCH SPI10触摸屏设备树 | 本机Windows MSHW0461/GTCH原始PnP/ACPI，现已实机成功 |
| iptsd/0001 | 上游v3.1.0到SL7分支的完整16文件差异 | 上游a83bc1232f7096f8b33b50fdbda249cd640de670 → alex-lentz 3663e96e758145801c3cb1ce7c72f362d0d4a5f5 |
| iptsd/0002 | 同步触点、多点槽、手指数和物理按钮状态 | 本机重复点击分层采样及46项回归验证 |
| iptsd-packaging/0001 | 升级时不重复触发hidraw探测 | 本次安装发现的systemd设备标签丢失问题；最终包3.1.0+sl7.2-1 |

每组按同目录series应用；打包补丁以DEBIAN目录为基线，不能当作iptsd源码补丁直接应用。最终DEBIAN控制文件已保存于iptsd-packaging/DEBIAN。

三份内核补丁对原Ubuntu源码零fuzz应用通过，触摸屏dtsi与已启动镜像构建输入一致；两份iptsd补丁重放后147个文件与实际构建输入一致，见validation/final-patchset-reproduction.json。

配置类修改另存config/system-root：UEFI推导Wi-Fi/蓝牙地址、最终指尖/拇指校准、systemd/udev集成、GRUB默认及回退。早期GPU固件别名、ath12k board-2板级覆盖和原始脚本在patchsets/firmware，部分二进制在恢复包。鼠标自动重连脚本已退役，历史在history。

旧I2C触屏补丁属于失败的错误硬件分支假设，未加入当前series。触控板flags0x08/type0x12热图缺失仍未解码；诊断脚本是只读工具，不是额外修复补丁。触屏供电保持开启的设备树已做功能验收，尚不代表完整睡眠/功耗验收。
